# CS-Training 商品采集助手（浏览器插件）

在淘宝 / 天猫 / 京东商品页一键采集**标题、价格、图片**到客服模拟接待训练系统的商品库。

## 原理

插件读取的是**你自己浏览器里已登录的商品页面**，不存储任何账号密码，
与正常浏览无异；系统服务器端不做任何账号模拟，无封号风险。

（抖音商品由系统服务端无头浏览器自动识别，已全自动，无需本插件。）

## 安装（一次性，约 1 分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」，选择本文件夹（`browser-extension`）
4. 安装后点 Chrome 右上角拼图图标 🧩，把「CS-Training 商品采集助手」**固定到工具栏**

## 使用

1. 在浏览器登录淘宝 / 京东（平时购物用的登录态即可）
2. 打开目标商品的商品详情页，等页面加载完
3. 点击工具栏上的插件图标 → 系统自动打开训练系统商品库，
   标题 / 价格 / 主图 / 详情图已自动填好，核对后**手动补填商品ID**并保存
4. 采集失败时系统页面会提示原因（通常是没登录或页面没加载完）

## 常见问题

- **点图标没反应 / 提示识别失败**：确认当前标签页是商品详情页（网址含
  item.taobao.com / detail.tmall.com / item.jd.com），并已登录。
- **价格或图片缺了**：平台页面改版会导致个别选择器失效，手动补一下，
  或联系维护者更新插件（只需替换 background.js 里的选择器）。
- **想在别的电脑用**：每台电脑重复一次安装步骤即可，无需账号。

## 修改系统地址

如果训练系统换了地址，编辑 `background.js` 第一行的 `SYSTEM_URL` 即可。
