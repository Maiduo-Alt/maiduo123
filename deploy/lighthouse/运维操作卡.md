## 日常速查（登录后执行）

```bash
cd /home/ubuntu/cs-training
C="docker compose -f deploy/lighthouse/docker-compose.yml --env-file .env"

$C ps                    # 看状态：api/web/postgres 都要 Up (healthy)
$C logs -f --tail=200 api    # 看后端日志（Ctrl+C 退出）
$C logs --tail=100 web       # 看前端/nginx 日志
ls -lh backups/          # 每日自动备份（容器 backup 写入，保留 30 份）
df -h /                  # 磁盘占用；docker system df 看镜像/卷占用
```

## 升级代码（GitHub 有新提交后）

```bash
cd /home/ubuntu/cs-training
sudo -u ubuntu git pull --ff-only origin main
nohup bash deploy/lighthouse/up.sh > /tmp/deploy.log 2>&1 &   # 后台构建，约 3~8 分钟
tail -f /tmp/deploy.log                                        # 看到「🎉 部署完成」即成功
```

## 数据库快查（容器内 psql）

```bash
docker exec -it cs-training-postgres-1 psql -U cs_training -d cs_training
# 常用：\dt 看表　 \d 表名 看结构　 select script_no,name from scripts order by id desc limit 5;
```

## 应急

| 情况 | 处理 |
| --- | --- |
| 服务挂了 | `bash deploy/lighthouse/up.sh`（自动重建+健康检查）；只重启不加 `--build` 用 `up.sh --no-build` |
| 数据误删 | 从 `backups/` 找最近 `.dump`，按 `deploy/lighthouse/迁移指南.md` §7「恢复备份」执行 |
| 端口不通 | 腾讯云控制台 → 防火墙 → 确认放行 TCP 8080（控制台防火墙独立于机器，脚本管不到） |
| 回滚版本 | `git checkout <旧提交>` 后重跑 `up.sh`（数据库前向兼容，回滚代码即可） |

## 红线

- 数据库在 `cs-training-postgres-1` 容器卷里，**不要删容器/卷**；删容器前先 `pg_dump` 备份
- 2G 内存余量小，`docker system prune` 清构建缓存可以，别加 `--volumes`
- 完整背景见 `deploy/lighthouse/迁移指南.md`；本卡只覆盖高频操作
